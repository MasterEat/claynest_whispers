# Clay Nest Whispers

Ελαφρύ, στατικό portfolio του Γιάννη Σωτηρόπουλου. Οι τέσσερις HTML σελίδες λειτουργούν απευθείας στο GitHub Pages, χωρίς framework, backend ή εγκατάσταση εξαρτήσεων για δημοσίευση.

## Τοπική προβολή και δημοσίευση

```sh
python3 -m http.server 8000
```

Δημοσιεύστε το περιεχόμενο του repository από τη ρίζα του branch στο GitHub Pages. Όλα τα assets και οι εσωτερικοί σύνδεσμοι είναι σχετικά και λειτουργούν κάτω από `/claynest_whispers/`. Το `robots.txt` περιλαμβάνεται για μελλοντικό custom domain· στο GitHub project hosting οι crawlers αναζητούν το robots στη ρίζα του host και ενδέχεται να αγνοήσουν αυτό το αρχείο υποκαταλόγου.

## Ενεργοποίηση φόρμας

Στο `assets/config.js`, αντικαταστήστε το `YOUR_FORM_ID` με το πραγματικό Formspree ID. Δεν χρειάζεται API key. Ρυθμίστε και επιβεβαιώστε τον παραλήπτη στο Formspree. Μέχρι τότε η φόρμα δεν αποστέλλει δεδομένα και παραπέμπει στο επιβεβαιωμένο Instagram. Η επιτυχία εμφανίζεται μόνο μετά από HTTP επιτυχία και JSON `{ "ok": true }` από το Formspree. Σε αποτυχία τα πεδία παραμένουν συμπληρωμένα· δεν αποθηκεύονται στοιχεία σε browser storage. Επιβεβαιώστε τις απαιτήσεις απορρήτου/συναίνεσης πριν ενεργοποιήσετε την πραγματική υπηρεσία.

## Αλλαγή domain

```sh
python3 tools/set-domain.py https://example.com/
```

Ενημερώνει τα στατικά canonical/Open Graph URLs, JSON-LD, sitemap, robots και το κοινό configuration. Δεν απαιτείται JavaScript για να διαβάσουν οι crawlers τα αρχικά metadata. Για επιστροφή στο GitHub Pages χρησιμοποιήστε `https://mastereat.github.io/claynest_whispers/`.

## CSS

Το `assets/tailwind.css` είναι ήδη compiled. Δεν χρησιμοποιείται Tailwind CDN ή runtime παραγωγής CSS. Για αλλαγές στις utility classes, με Node/npm διαθέσιμο:

```sh
npx --yes --package tailwindcss@3.4.19 tailwindcss -c tools/tailwind.config.cjs -i tools/tailwind.input.css -o assets/tailwind.css --minify
```

Το κοινό responsive styling βρίσκεται στο `assets/site.css`, η συμπεριφορά στο `assets/site.js`. Χρησιμοποιούνται system fonts και inline SVG icons χωρίς εξωτερικές βιβλιοθήκες. Το `assets/favicon.svg` είναι το προσωρινό favicon μονογράμματος.

## Περιεχόμενο προς επιβεβαίωση

- Όλες οι υπάρχουσες εικόνες διατηρούν τα αρχικά URLs. Το `lh3.googleusercontent.com` αποκλείστηκε από το δίκτυο του περιβάλλοντος κατά τον έλεγχο, οπότε δεν επιβεβαιώθηκε η οπτική/φωτογραφική γνησιότητά τους ή η εξωτερική τους διαθεσιμότητα. Χρειάζονται εγκεκριμένες φωτογραφίες έργων και πραγματικό πορτρέτο του δημιουργού. Μετά την επιβεβαίωση προτιμώνται τοπικά, βελτιστοποιημένα αρχεία εικόνων, με πραγματικές διαστάσεις.
- Οι υπάρχοντες τίτλοι, περιγραφές, υλικά, διαστάσεις, χρονολογίες και ενδείξεις διαθεσιμότητας αποτελούν demo στοιχεία. Δεν έχουν προστεθεί νέα στοιχεία έργων. Οι σχετικές σελίδες και το modal τα επισημαίνουν ως ανεπιβεβαίωτα.
- Οι λεπτομέρειες διαδικασίας, οι δυνατότητες αναθέσεων και οι φωτογραφικές λεζάντες χρειάζονται έγκριση. Αφαιρέθηκαν ανεπιβεβαίωτη χρονολογία ίδρυσης, συγκεκριμένη έδρα στην Αθήνα, υποσχέσεις χρόνου απόκρισης και ισχυρισμός ζωντανής ροής Instagram.
- Χρειάζεται το πραγματικό Formspree ID και δοκιμαστική πραγματική αποστολή από τον ιδιοκτήτη μετά τη ρύθμιση.
- Δεν έχει οριστεί social sharing image μέχρι να επιλεγεί εγκεκριμένη αυθεντική φωτογραφία. Δεν έχουν προστεθεί διεύθυνση, τηλέφωνο ή εμπορικά στοιχεία.

## Έλεγχοι

Browser smoke tests σε Chromium: τέσσερις σελίδες σε 360/390/768/1440 px, horizontal overflow, mobile menu, φίλτρα, τέσσερα artwork modals, focus trap/επιστροφή εστίασης, Escape/backdrop και μεταφορά τίτλου στη φόρμα. Έλεγχοι φόρμας: native validation, αποκλεισμός placeholder, mocked success/HTTP error/network failure — χωρίς πραγματικές αποστολές. Οι εξωτερικές εικόνες δεν φορτώθηκαν λόγω του περιορισμού δικτύου που αναφέρεται παραπάνω.

Επανάληψη browser smoke test (προαιρετικό εργαλείο ανάπτυξης: Python Playwright και Chromium):

```sh
# Με τον static server ήδη ενεργό στη σωστή θύρα:
SITE_URL=http://127.0.0.1:8000/ python3 tools/smoke_test.py
```

Ορίστε `CHROMIUM_PATH` αν το Chromium δεν βρίσκεται στο PATH. Τα screenshots γράφονται στο `/tmp/`. Δεν απαιτείται κανένα από αυτά τα εργαλεία για τη δημοσίευση του site.
